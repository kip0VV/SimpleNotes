# Исправления после аудита кода · 15 ноября 2026

- Цвет: операции используют штатный markdown-it и source maps его блоков/inline-правил. Несколько строк оформляются отдельно. Очистка удаляет затронутую обёртку целиком; примеры в fenced/inline-коде сохраняются. Сравнение дерева Markdown до/после отклоняет повреждающее разметку выделение. Операция регистрируется одним действием отмены.
- Оглавление: Unicode-адреса заголовков, уникальные суффиксы и обработчик прокрутки по `#fragment` в WebKit. Простое разрешение навигации не работало в реальном about:blank — это обнаружено кликом при проверке интерфейса.
- Сохранение: предыдущий inode перемещается в `.simplenotes-history`, проверяется его содержимое, затем подготовленный файл публикуется через macOS `renamex_np(RENAME_EXCL)`. Заранее сохраняется и снимок новой версии. Это сохраняет поздние записи внешнего редактора через открытый дескриптор. Конфликт не перезаписывает появившийся файл. При переименовании исходник архивируется вместо удаления.
- Обычная кнопка сохранения, отметка задачи и таймер быстрой заметки выполняют файловую операцию в отдельной очереди. Завершение не сбрасывает новые правки, сделанные во время записи. Переход к другой заметке блокируется до завершения записи. Сохранение из диалога ухода/закрытия быстрой заметки остаётся синхронным, чтобы подтвердить запись перед переходом.
- Черновики записываются после 400 мс паузы; закрытие и переходы принудительно сохраняют актуальное состояние. Аварийное завершение может потерять последние 400 мс набора.
- Настройки и черновики разделены по каноническому пути библиотеки. Переключение сохраняет напоминания, цвета, порядок и свёрнутые папки. Уведомления планируются для активной библиотеки.
- Индекс: ошибки отдельных файлов/подпапок не обрывают всю библиотеку; нечитаемая заметка видна по имени, её старое содержимое удаляется из кэша, число ошибок показано рядом с поиском, детали доступны в подсказке. Отмена проверяется при обходе. Файлы в истории версий скрыты от индекса.
- Поиск: задержка 150 мс при наборе, фоновое сканирование текста свыше 100 000 UTF-16 единиц, кэш диапазонов при переходе между совпадениями, подсветка порциями по 1000. Поколения запросов не позволяют старому результату подсветить новый текст.

История версий намеренно не удаляется автоматически: в старый inode ещё может писать внешний редактор. Она занимает дополнительное место. Это реальные сохранённые файлы, а не заглушка. Доставка системных уведомлений не проверена без разрешения ОС для отдельной тестовой сборки.

## Проверки

Node: стили, вложение, форматирование, формулы, Unicode-заголовки, списки/цитаты из нескольких строк, очистка части фразы, код в цитате, пересечение маркеров Markdown.

Нативные регрессии: реальный AppKit/WebKit, история двух конкурирующих версий через открытый дескриптор, конфликт сохранения, продолжение набора во время записи, битый UTF-8, отмена обхода, восстановление состояния библиотек, отмена фонового поиска. Результат последнего полного прогона: `PASS: all regression checks completed at 2026-11-15 10:50:37 +0000`.

Ручной CUA-прогон в изолированной копии приложения: выделено слово внутри цветной фразы, снят цвет и отменена операция через ⌘Z; выделены два пункта списка и применён фон; проверены сохранение списочной структуры, буквальный пример разметки в коде и реальная формула.
