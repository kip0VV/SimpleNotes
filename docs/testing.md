# Проверка функций SimpleNotes 0.3.2

Проверка выполнена 10 ноября 2026 года на Apple Silicon с macOS 26.3. Файловые сценарии выполнялись в отдельных временных библиотеках. Установленное приложение обновлено, содержимое личных заметок сверено по SHA-256.

## Воспроизведение

```sh
./scripts/test.sh
./scripts/package.sh
```

Тесты компилируются в отдельный пакет `SimpleNotesTests.app` с собственным идентификатором и пользовательскими настройками. Они создают временные файлы и удаляют свои настройки после успешного прогона. Markdown проверяется в настоящем WKWebView с включённым в приложение рендерером.

## Исправления по результатам прогона

- В напоминании появились отдельные поля даты и времени с прямым вводом `ЧЧ:ММ`. Проверены ввод с клавиатуры, повторное открытие после ошибки, проверка границ времени и объединение даты с временем.

- Отмена и повтор в редакторе и Markdown-просмотре теперь сообщают об изменении текста. Отмена сохранённой галочки требует сохранения перед переходом.
- Контекстное меню позволяет перенести заметку из темы в корень библиотеки.
- Перечисление файлов сохраняет представление пути выбранной библиотеки. Системные варианты `/var` и `/private/var` больше не ломают вложенный выбор темы.

## Ограничения

Этот прогон не охватывает длительную работу, физические перетаскивания на тачпаде, доставку после полного выхода, переход по уведомлению, запуск на Intel и каждый поддерживаемый выпуск macOS. Неподтверждённые сценарии в таблице требуют отдельного ручного прогона.

## Проверка доставки

10 ноября тестовое напоминание на 11:09 доставлено системой в 11:09. Журнал macOS подтвердил показ баннера со звуком, пользователь подтвердил получение. Предыдущее напоминание хранилось на 12:01 при ожидавшемся 11:01. Изменений кода планирования по результатам этой проверки не потребовалось.

## Список и повторы

Активные напоминания показаны отдельным блоком над обновлением списка. Проверены сортировка по ближайшей дате, переход к заметке, действия изменения и отмены, пустое и выключенное состояния. Поддерживаются системные повторы каждый час, день, неделю и месяц. Для повтора показывается ближайшее подходящее время. Месячный повтор пропускает месяцы без выбранного дня. Автотесты проверяют расчёт ближайших дат и нативные повторяющиеся триггеры. Получение повторов после полного выхода отдельно не проверено.

## Большое число напоминаний

Боковая панель показывает три ближайших записи и общее число активных напоминаний. «Все…» открывает отдельное изменяемое по размеру окно с нативной таблицей, поиском по заметке и папке, фильтрами «Сегодня», «7 дней», «С повтором», сортировкой по дате или названию. Выбор сохраняется при обновлении и сортировке. Автотесты на 1000 тестовых записей проверяют поиск, фильтры, сортировку, выбранную строку и состояния кнопок. Отдельно проверены ограничение бокового блока тремя строками, переход к заметке и отмена выбранного напоминания. Массовая доставка уведомлений этим прогоном не проверялась.

## Критические пограничные сценарии

Добавлены детерминированные проверки запоздалых ответов планировщика после переноса, повторного изменения того же времени, отмены и создания нового напоминания, отключения уведомлений и смены библиотеки. Проверены откат текущего неудачного запроса, явная ошибка для прошедшего времени и некорректной записи, сохранение одного файла через разные эквивалентные URL. Тестовый процесс ограничен 90 секундами для обнаружения зависания. Отдельный стресс-сценарий рассчитывает месячные повторы для 1000 существующих файлов. Ответы планировщика в сценариях гонок моделируются вызовом обработчика завершения. Длительный прогон и полный часовой цикл этим набором не покрываются.


### Графит и уменьшенная панель

Проверка отдельной сборки на тестовой библиотеке: при масштабе верхней панели 90% и блока тем 85%, с длинным названием выбранной темы, кнопка «+ Тема» сохраняет полную подпись. Визуально проверены обычное и компактное окна графитовой темы. Проверены применение графитовых цветов и возврат к системным цветам, автосохранение быстрой записи в тот же файл, сохранение выделения при разворачивании и открытие следующей пустой записи.


### Запуск быстрой записи без показа основного окна

Подготовка интерфейса теперь проходит без показа окна. Обычный запуск открывает основное окно через событие открытия приложения; запуск системной службой ожидает команду быстрой записи. Событие службы определяется по `keyAEPropData == keyAELaunchedAsServiceItem`. Ранний вызов горячей клавиши ставится в очередь до готовности интерфейса.

В отдельной сборке на тестовой библиотеке проверено, что окно остаётся невидимым после подготовки и до включения компактного режима. Все регрессионные проверки также завершились успешно при запуске тестового приложения через LaunchServices. Успешный прогон создаёт `build/test-result.txt` с датой; запуск тестового скрипта удаляет прежний отчёт.


### Исправления мини-окна и обычных текстовых файлов

`Tests/BugFixChecks.swift` проверяет обновление названия после первого автосохранения и защиту существующего файла при совпадении имён, сохранение ручного названия в основном окне, отсутствие зависшего статуса у пустой записи, синхронизацию папок мини-окна и фактическое место записи после смены библиотеки.

Для `.txt` и `.md` проверены полный показ и индексирование обычного текста со строкой `Тема —`, сохранение без добавления служебного заголовка и безопасное переименование. Старые заголовки SimpleNotes с корректной датой остаются читаемыми, включая вариант без пустой строки перед текстом. Невозможная дата не распознаётся как служебный заголовок.


### Изменяемая высота и скрытие напоминаний

`Tests/ReminderPanelChecks.swift` проверяет увеличение числа видимых строк, скрытие перетаскиванием ниже порога, синхронизацию галочки в настройках, сохранение высоты и видимости, восстановление блока и ограничение высоты в маленьком окне. Скрытие блока сохраняет записи напоминаний и настройки уведомлений. Отрисовка при перетаскивании использует готовый список, не перечитывая библиотеку на каждом движении мыши.

На отдельной тестовой библиотеке также проверены реальные размеры элементов: скрытый блок имеет нулевую высоту и освобождает место списку заметок. Через интерфейс проверено перетаскивание до скрытия, автоматическое включение галочки и её ручное выключение.

## Формулы LaTeX

`node Tests/markdown-math.cjs` проверяет пример с параметрическими функциями, четыре разделителя, индексы, блоки кода, экранирование, цены, ошибки и запрет небезопасных команд. Node нужен только для этой проверки.

`RefreshFeedbackChecks.swift` проверяет подтверждение ⌘R, завершение фонового чтения, повторное обновление без изменений, вытеснение запроса более новым сканированием и сохранность открытого текста.
