# Проверка функций SimpleNotes 0.2.3

Проверка выполнена 10 ноября 2026 года на Apple Silicon с macOS 26.3. Файловые сценарии выполнялись в отдельных временных библиотеках. Установленное приложение обновлено, содержимое личных заметок сверено по SHA-256.

## Воспроизведение

```sh
./scripts/test.sh
./scripts/package.sh
```

Тесты компилируются в отдельный пакет `SimpleNotesTests.app` с собственным идентификатором и пользовательскими настройками. Они создают временные файлы и удаляют свои настройки после успешного прогона. Markdown проверяется в настоящем WKWebView с включённым в приложение рендерером.

## Исправления по результатам прогона

- В напоминании появились отдельные поля даты и времени с прямым вводом `ЧЧ:ММ`. Проверены ввод с клавиатуры, повторное открытие после ошибки, проверка границ времени и объединение даты с временем.

- Отмена и повтор в редакторе и Markdown-просмотре теперь сообщают об изменении текста. Отмена сохранённой галочки требует сохранения перед переходом.
- Контекстное меню позволяет перенести заметку из темы в корень библиотеки.
- Перечисление файлов сохраняет представление пути выбранной библиотеки. Системные варианты `/var` и `/private/var` больше не ломают вложенный выбор темы.

## Ограничения

Этот прогон не охватывает длительную работу, физические перетаскивания на тачпаде, доставку после полного выхода, переход по уведомлению, запуск на Intel и каждый поддерживаемый выпуск macOS. Неподтверждённые сценарии в таблице требуют отдельного ручного прогона.
