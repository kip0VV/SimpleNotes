# Цвет текста и фон

Выдели слова в редакторе, затем нажми «Раскрасить» и выбери смысловой стиль, цвет текста или фона в ряду форматирования. В рендере показываются выбранные цвета. «Раскрасить → Убрать цвет и фон» снимает оформление с выделенного текста. Обычная отмена ⌘Z возвращает предыдущее состояние.

В рендере также можно выделить уникальный фрагмент обычного текста и выбрать цвет: приложение найдёт его в исходнике и откроет редактор с применённой разметкой. Для повторяющихся фрагментов и сложного Markdown выделяй текст в редакторе — это позволяет точно выбрать нужное место.

## Инструкция для Codex

Цвета записываются прямо в Markdown, без HTML и отдельной базы данных. Можно попросить:

> В этой заметке обозначь названия тем стилем topic, определения — definition, важные условия — important, примеры — example. Не меняй формулировки и формулы. Раскрашивай только обычный текст, заголовки, жирный текст и курсив. Не размечай таблицы, списки, цитаты, ссылки, изображения, формулы, код и абзацы со сложным форматированием.

| Назначение | Разметка |
| --- | --- |
| Тема, оранжевый текст | `[Производная]{topic}` |
| Определение, голубой фон | `[Мгновенная скорость изменения функции]{definition}` |
| Важно, жёлтый фон | `[Знаменатель не равен нулю]{important}` |
| Пример, зелёный текст | `[Например, квадрат числа]{example}` |
| Произвольный цвет текста | `[слово]{text-orange}` |
| Произвольный цвет фона | `[слово]{bg-blue}` |
| Текст и фон вместе | `[[слово]{text-orange}]{bg-blue}` |

Доступные цвета: `orange`, `blue`, `green`, `yellow`, `pink`, `purple`. Внутри выделения поддерживаются жирный текст, курсив и формулы: `[**Тема** и $x^2$]{topic}`. Не разрывай цветовым оформлением одну формулу, ссылку или блок кода. У заголовков оставляй `#` снаружи: `# [Название]{topic}`; внутри можно использовать жирный текст и формулы. Приложение также отображает ранее сохранённый вариант `[# Название]{topic}` как цветной заголовок. Разметка предназначена для фрагментов внутри абзаца, а не для оборачивания нескольких абзацев или всей таблицы. При выделении целой строки кнопка сохраняет маркеры списка, задачи и цитаты снаружи цвета. Для строчного кода выделяй фрагмент вместе с обратными кавычками; цветная метка внутри кода показывается буквально. Окрашивание целого блока кода и нескольких абзацев одной меткой не поддерживается. Другие Markdown-просмотрщики могут показывать эту расширенную разметку как текст.

## Темы приложения

«Настройки → Основные → Тема приложения» содержит обе темы: «Матовый оранжевый» с тёплыми тёмными поверхностями и приглушёнными акцентами и «Графит · мягкий голубой». Тема интерфейса не меняет цветовые метки в заметках; для светлого и тёмного оформления подобраны отдельные оттенки меток.


При выборе нескольких строк приложение раскрашивает текст каждой строки отдельно, сохраняя маркеры заголовков, списков и цитат. Перед применением оно сравнивает структуру Markdown: выделение, которое разрывает форматирование, отклоняется с объяснением. Содержимое блоков кода и частей формул защищено. «Убрать цвет и фон» снимает затронутые цветовые обёртки целиком, включая обёртку вокруг частично выделенной фразы. Так сохраняются вложенные жирный текст, ссылки и формулы; буквальные метки в коде не меняются. Изменение отменяется обычным ⌘Z.

Заголовки получают адреса по тексту: `## Моя тема` → `[Перейти](#моя-тема)`. У повторяющихся заголовков добавляются суффиксы `-1`, `-2`; цветовые метки не входят в адрес.


## Ограничение раскраски после 0.4.0

Кнопка разрешает новую раскраску только обычного текста, заголовков, жирного текста и курсива. Таблицы (в том числе строки с `|`, которые уже не распознаются как таблица), списки, цитаты, зачёркнутый текст, ссылки, картинки, формулы и код защищены. При попадании выделения в такой блок операция отклоняется целиком, без изменения текста. Если абзац содержит сложное inline-форматирование, защищён весь абзац. Это ограничение заменяет описанные выше возможности редактирования сложных элементов. Отображение ранее сохранённых цветов не отключено. Очистка цвета остаётся доступной, в том числе для восстановления таблицы после снятия меток; некорректные разделители таблицы она не исправляет.
